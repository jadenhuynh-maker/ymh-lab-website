# Youth Mental Health Lab website

Open `index.html` for the homepage or `research.html` for the Research page. Both use `styles.css`. The homepage uses the lab’s existing logo and the brain–body visual from the lab presentation. The eight project summaries are adapted from the current YMH Lab research page. Other navigation and project detail links lead to the live site during the migration.

## GitHub Pages

1. Put the contents of this folder in a dedicated GitHub repository on the `main` branch.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Open the published link from the Pages settings once deployment finishes.

Only this website folder belongs in the publishing repository. The surrounding lab workspace contains research files.
